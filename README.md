# 📅 Бот «Календарь эфиров»

Telegram-бот: календарь, где даты с эфирами помечены 🎬. Клик по дате открывает
карточку эфира с кнопками-ссылками на YouTube и ВКонтакте.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/start`, `/calendar` | все | открыть календарь |
| `/id` | все | узнать свой Telegram ID |
| `/add дата \| название \| описание \| yt \| vk` | админ | добавить эфир |
| `/del 2026-08-10` | админ | удалить эфир |
| `/list` | админ | список всех эфиров |

Пример добавления:

```
/add 2026-08-10 | Разбор портфолио | Отвечали на вопросы зрителей | https://youtu.be/XXXX | https://vk.com/video-123_456
```

## Запуск на Bothost.ru

1. Создайте бота у @BotFather → получите токен.
2. Залейте эту папку в свой GitHub-репозиторий.
3. На Bothost: **Создать проект → Telegram → Python**, подключите GitHub-репозиторий
   (при пуше в ветку бот будет обновляться автоматически).
4. Файл запуска: `bot.py`. Зависимости подтянутся из `requirements.txt`.
5. В переменных окружения проекта задайте:
   - `BOT_TOKEN` — токен от BotFather
   - `ADMIN_IDS` — ваш Telegram ID (узнать: команда `/id` у бота или @userinfobot).
     Несколько админов — через запятую: `123456789,987654321`
6. Нажмите «Старт».

## Локальный запуск (для проверки)

```bash
pip install -r requirements.txt
BOT_TOKEN=ваш_токен ADMIN_IDS=ваш_id python bot.py
```

## Хранение данных

Эфиры лежат в `streams.json` рядом с ботом. Важно: если контейнер на хостинге
пересоздаётся из репозитория, файл может сброситься к версии из Git — поэтому
после добавления эфиров через `/add` периодически коммитьте актуальный
`streams.json` в репозиторий (или храните все эфиры сразу в нём).
